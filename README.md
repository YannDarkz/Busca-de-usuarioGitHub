# Projeto de Busca de Usuários do GitHub
Repositório contendo os arquivos do projeto de Fetch e GitHub API.

## Utilizando o Programa
* Para utilizar a ferramenta de busca de usuários do GitHub, basta acessar a página, pesquisar o nome do usuário na area indicada.

* Após o passo anterior ser feito, se o usuário for existente irá carregar O perfil, no máximo 10 repositórios mais recentes e os 10 ultimos eventos desse usuário.

### Linguagens Utilizadas
* HTML
* CSS
* JavaScript
